## FlowRoute – Documents Repository

This repository contains all official documentation related to the FlowRoute project for SENG 31242 – System Design Project.

## Repository Purpose

This repository is used to manage:

- SRS documents
- SDS documents
- UML diagrams
- Meeting notes
- Sprint retrospectives
- ADRs (Architectural Decision Records)
- Pitch decks
- Presentation materials
- Planning artefacts
