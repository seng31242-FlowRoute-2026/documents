# Use Case Description: UC-03 Manual Task Reassignment

| Field | Content |
| :--- | :--- |
| **Use Case ID** | UC-03 |
| **Use Case Name** | Manual Task Reassignment |
| **Primary Actor** | Product Owner (PO) |
| **Secondary Actor(s)** | Editing Pods, Notification Service |
| **Preconditions** | 1. The Product Owner is securely authenticated into the administrative dashboard.<br>2. The automated routing engine (`UC-02`) has flagged a capacity bottleneck or a manual override is requested. |
| **Postconditions (Success)** | 1. The video task is updated with a forced Editing Pod assignment.<br>2. The real-time Pod Workload Dashboard reflects the updated queue state immediately. |
| **Main Success Flow (AC1)** | 1. The Product Owner logs into the administrative dashboard interface.<br>2. The PO selects an active, blocked video task from the bottleneck queue view.<br>3. The PO selects an alternative target Editing Pod to handle the workload.<br>4. The PO clicks the "Force Reassign" button.<br>5. The system processes the administrative assignment override and updates the database task record.<br>6. The system pushes a notification to the selected Editing Pod and updates the live Workload Dashboard metrics. |
| **Alternative Flow A: Target Pod Manual Rejection (AC2)** | 1. At step 5 of the main flow, the selected target Editing Pod instance rejects the forced assignment (e.g., due to sudden technical hardware failure, node disconnection, or an absolute hard resource cap).<br>2. The system catches the assignment failure exception.<br>3. The system halts the transaction, rolls back the assignment state, and displays an error message: "Manual Assignment Failed: Target Pod rejected allocation."<br>4. The task retains its original queue state. |
| **Alternative Flow B: Task State Conflict** | 1. If an internal editor completes and marks the video task as 'Rendered' while the PO is actively viewing the reassignment page, a state conflict occurs.<br>2. Upon the PO clicking "Force Reassign", the system detects the state modification.<br>3. The system aborts the override transaction and displays an informational message: "Reassignment Aborted: Task already completed." |
