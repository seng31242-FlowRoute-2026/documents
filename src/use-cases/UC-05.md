# UC-05: Final Delivery Download

| Field | Content |
|-------|---------|
| **Use Case ID** | UC-05 |
| **Use Case Name** | Final Delivery Download |
| **Actor(s)** | Client, FlowRoute System |
| **Preconditions** | The video task status has been set to "Completed" (UC-04); the final rendered video file has been stored in the system and is ready for download; the client has a registered account. |
| **Postconditions - Success** | The client successfully downloads the final rendered video file; the system marks the video asset's lifecycle as closed; a download event is logged with client ID, video ID, and timestamp. |
| **Postconditions - Failure** | the video file is not downloaded; the system logs the failed attempt; the client is notified with the reason for failure. |
| **Main Flow** | 1. System notifies the client that their final rendered video is ready for download. <br>2. Client logs in to the FlowRoute portal and navigates to their delivery dashboard. <br>3. Client clicks the Download button for the completed video asset. <br>4. System authenticates the client's identity and verifies they are the owner of the requested video asset. <br>5. System generates a secure, time-limited download link for the video file. <br>6. Client clicks the download link and the file transfer begins. <br>7. System logs the download event with client ID, video ID, and timestamp. <br>8. System marks the video asset lifecycle as closed upon successful download completion. |
| **Alternative Flow 1** | At step 4: If the client's authentication fails or they are not the verified owner of the asset, the system denies access and displays an authorisation error. The client is prompted to log in again or contact support. No download link is generated. |
| **Alternative Flow 2** | At step 6: If the download link has expired (link lifetime exceeded) before the client clicks it, the system displays an expiry message. The client may request a new download link, which returns the flow to step 5. |
| **Alternative Flow 3** | At step 6: If the file transfer fails midway (e.g., network interruption), the system retains the download link for the remainder of its valid period so the client can restart the download without repeating authentication. |
| **Business Rules** | BR-14: Download links are time-limited and expire after 24 hours of generation. <br>BR-15: Only the verified owner client account may download a given video asset.<br> BR-16: Each download event must be logged with client ID, video ID, and timestamp for audit purposes. <br>BR-17: A video asset lifecycle is marked closed only after a successful, complete file transfer. |
